# COURT Wave

Use this skill to create or update COURT waves.

## Wave requirements

- Define a product-neutral scalable experience framework goal.
- Identify affected crates and downstream engine adapters.
- Break the wave into small pulses.
- Include validation expectations for every pulse.
- Record non-goals.

# COURT Review Panel

COURT reviews keep portable experience contracts product-neutral,
evidence-backed, and rehearsed by RACKET.

## Active Roles

| Role | Protects | Invoke when |
|---|---|---|
| [Framework Steward](framework-steward.md) | COURT scope and product neutrality | Changing snapshots, actions, scenes, or non-goals |
| [Engine Adapter Architect](engine-adapter-architect.md) | Runtime handoff and compatibility | Changing adapter or unsupported-feature behavior |
| [Game Design Methods Reviewer](game-design-methods-reviewer.md) | Iteration, critique, playtest, and rules clarity | Changing design-method or validation contracts |
| [Experience Assessment Reviewer](experience-assessment-reviewer.md) | Bounded learning and impact claims | Adding assessment or simulation hooks |
| [Source Custody Reviewer](source-custody-reviewer.md) | Course, media, student-work, and rights boundaries | Using research or third-party material |

## Core Tensions

| Pulls | Against | Because |
|---|---|---|
| Framework Steward | Engine Adapter Architect | Runtime convenience can leak engine behavior into portable contracts. |
| Game Design Methods Reviewer | Framework Steward | Richer design practice can over-expand the minimal core. |
| Experience Assessment Reviewer | Game Design Methods Reviewer | Measurable hooks can be mistaken for evidence of successful experience. |
| Source Custody Reviewer | Framework Steward | Useful research precedent does not automatically become reusable product material. |

## Review Order

1. Source Custody Reviewer establishes usable evidence.
2. Framework Steward establishes ownership and scope.
3. Engine Adapter Architect rehearses RACKET compatibility.
4. Game Design Methods and Experience Assessment reviewers bound the claims.
